## ADDED Requirements

### Requirement: Consistent button order
The article note editor, the Notes page edit form and the highlight popover SHALL show their buttons in the order Save, Cancel (Close in the popover), Delete, with Delete last.

#### Scenario: Same order everywhere
- **WHEN** any of the three editors is open on a note that can be deleted
- **THEN** its buttons read Save, Cancel or Close, Delete from first to last
